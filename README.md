Hi, I'm Amir! I'm a Computer Science Ph.D. from UC Riverside based in beautiful Massachusetts 🎄

My research focuses on computational biology, with interests in non-coding RNAs, genome editing (CRISPR), algorithm design, and large-scale data analysis. I build open-source tools that help make biological data more accessible, efficient, and scalable.

🧬 Most recent projects include:
- ALLEGRO – ultra-compact CRISPR guide library design across species
- Agentic ALLEGRO – configure and run ALLEGRO by just describing your experiment needs in English
- SIRIUS – efficient and optimal divergent synonymous gene design
- FUGUE – unified genome downloader for 2,000+ fungal species
- RNA-seq Pipeline – step-by-step comprehensive bulk RNA-seq analysis
- MSTMap Online – performant web-server for linkage mapping, and its companion Python library

Outside the terminal, you’ll find me climbing, hiking, practicing _Deutsch_, or playing guitar 🎸
